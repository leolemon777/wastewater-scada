============================================================
  污水 SCADA 监控系统 - 工控机部署说明
============================================================

【一、原理】
本项目是纯静态前端(HTML/JS/CSS)，无后端依赖。
工控机只需 Windows 自带的 PowerShell，通过内置 HttpListener
提供 HTTP 服务，浏览器访问即可，不需要安装 Node.js。

【二、打包清单】(从开发机拷到工控机的文件)

工控机目标目录示例: D:\SCADA\

    D:\SCADA\
    ├── dist\                              ★ 必需，npm run build 的产物
    │   ├── index.html
    │   └── assets\
    ├── scripts\
    │   ├── windows-serve-dist.ps1         必需(本机访问)
    │   └── windows-serve-dist-lan.ps1     推荐(局域网访问)
    └── 启动SCADA_工控机.bat               必需，启动入口

★ 注意：不要拷 node_modules、src、package.json，工控机用不到。
★ 更新版本时：只需替换 dist\ 目录即可。

------------------------------------------------------------
【三、首次部署步骤】

1. 开发机上执行构建(在项目根目录)：
       npm run build
   产物在 dist\ 目录。

2. 把上面【打包清单】里的 4 项(dist + scripts + bat)
   整体拷贝到工控机，比如 D:\SCADA\

3. 双击「启动SCADA_工控机.bat」。
   - 现场只在本机看：直接双击即可。
   - 要让同网段其他电脑也能看：右键 → 「以管理员身份运行」。
     (因为监听所有网卡 http://+:8080 需要管理员权限)

4. 浏览器会自动打开 http://127.0.0.1:8080/

------------------------------------------------------------
【四、让其他电脑访问(局域网)】

1. 以管理员身份运行「启动SCADA_工控机.bat」。
2. 开 Windows 防火墙入站规则，放行 8080 端口：
       以管理员身份打开 PowerShell，执行：
       New-NetFirewallRule -DisplayName "SCADA 8080" `
         -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
3. 其他电脑浏览器访问: http://工控机IP:8080/
   (工控机 IP 在启动窗口里会打印出来，或在工控机执行 ipconfig 查看)

------------------------------------------------------------
【五、开机自启动】(工控机断电恢复后自动起来)

方法 A - 启动文件夹(最简单)：
   1. Win+R 输入: shell:startup  (打开启动文件夹)
   2. 把「启动SCADA_工控机.bat」的快捷方式拖进去
   3. 如需管理员权限(局域网访问)，右键快捷方式 → 属性 →
      快捷方式 → 高级 → 勾选「用管理员身份运行」
   缺点: 会弹出窗口，需用户登录后才启动。

方法 B - 计划任务(推荐，无需登录)：
   以管理员身份打开 PowerShell，执行(按实际路径修改):

   $action = New-ScheduledTaskAction `
       -Execute "D:\SCADA\启动SCADA_工控机.bat" `
       -WorkingDirectory "D:\SCADA\"
   $trigger = New-ScheduledTaskTrigger -AtStartup
   $settings = New-ScheduledTaskSettingsSet `
       -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries `
       -StartWhenAvailable -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1)
   Register-ScheduledTask -TaskName "SCADA" `
       -Action $action -Trigger $trigger -Settings $settings `
       -RunLevel Highest -Force

   -RunLevel Highest = 用最高权限(满足 http://+:8080)
   -AtStartup = 开机即启动，无需用户登录

【六、常见问题】

Q: 打开页面是白屏？
A: 1) 确认 dist\index.html 存在
   2) 确认地址是 127.0.0.1:8080 而非 file:// 直接打开 html
   3) F12 看控制台报错，多半是 dist 没拷全(漏了 assets\)

Q: 局域网其他电脑打不开？
A: 1) bat 必须以管理员身份运行(否则只监听 127.0.0.1)
   2) 防火墙没放行 8080 端口(见第四节)
   3) 工控机和其他电脑不在同一网段

Q: 8080 端口被占用？
A: 编辑 scripts\windows-serve-dist-lan.ps1 第 7 行 $port = 8080，
   改成 8081 / 8888 等空闲端口，bat 里浏览器地址也同步改。

Q: 浏览器提示不安全 / 证书错误？
A: 这是 http 不是 https，正常现象，工控局域网内可忽略。
   Edge/Chrome 在地址栏手动输入 http:// 前缀即可。

Q: 想要全屏 / 大屏常驻？
A: 浏览器按 F11 全屏。Chrome 可加启动参数 --kiosk 全屏无地址栏。

------------------------------------------------------------
【七、停止服务】
   关闭弹出的「SCADA-Server」黑色窗口即可。
   或在任务管理器结束 powershell.exe(注意别关错)。
