# 浏览器部署

当前项目是纯浏览器前端，不再包含 Electron 或 Windows EXE 打包逻辑。

## 构建

在项目根目录执行：

```bash
npm ci
npm run verify:scene
```

构建产物位于 `dist/`。必须完整部署整个目录，不能只复制 `index.html`。

## 部署方式

- 开发机预览：`npm run preview -- --host 0.0.0.0`
- 现场长期运行：将 `dist/` 发布到 IIS、Nginx 或其他静态文件服务器
- 更新版本：重新构建后整体替换服务器上的 `dist/`

Vite 的 `preview` 命令适合验收，不建议作为长期生产服务器。项目使用相对资源路径，可部署在站点根目录或子目录。

## 工控机注意事项

- 浏览器必须支持 WebGL 2，建议使用当前版本的 Edge 或 Chrome。
- 大屏常驻可使用浏览器 kiosk 模式。
- 远程桌面环境可能禁用或降低 GPU 加速，3D 异常时优先在本机浏览器验证。
