> **气浮 AI1 换算（2026-08-19 用户确认）**：AI1 为 4-20mA 模拟量，对应 PH 量程 0-14，公式 `pH = (mA - 4) / 16 * 14`。当日实测 9516 uA = 9.516 mA ≈ pH 4.83。此通道为 PH 变送模拟输出，可绕开 RS485 主站冲突直读 PH（RS485 点表 `node0101/40001` 仍归有人云采集，两者数据源同仪表）。
>
> **地下池 AI1 换算**：AI1 4-20mA 对应液位 0-5m，公式 `level = (mA - 4) / 16 * 5`。2026-08-19 实测 16.08 mA ≈ 3.78 m。
>
> **默认 `.7` = 混合池（2026-08-19 用户确认保留）**：用户明确混合池 M100 故意不改 IP、保持 `192.168.0.7`（现场只有它一台 `.7`）。实测 `.7` 为独立真设备（MAC `D4-AD-20-C1-2C-D4`，随用户当日巡查开机，运行 43min 时读到），IO 全 0（迁装后传感器未接线，属预期）。读 `.7` 时依赖电脑上 6-30 调试残留的主机路由 `192.168.0.7/32 → 以太网 .60`（metric 26）绕开占用同 IP 的 WLAN 2——该路由勿删；若某天读不到 `.7`，先检查该路由是否存在。

## 改 IP 标准流程（M100 内置网页）

1. 网线直连目标 M100；电脑网卡设 `192.168.0.100` / `255.255.255.0`。
2. 浏览器 `http://192.168.0.7` → 账号 admin / 密码 admin（注意与网桥的 `admin01` 不同；密码不写入 git 文档）。
3. **先核对页面 SN 是目标设备**（多台默认 `.7`，插错就改错）。
4. 「以太网/EtherNET」→ IP 获取方式选 Static IP → 填本机 IP / 掩码 `255.255.255.0` / 网关 `192.168.0.1`。
5. 保存 → 自动重启约 30s → 用新 IP 访问 `ioread.cgi` 验证。

## 关键操作与红线

- 读 IO：`http://192.168.0.x/ioread.cgi?read`（只读本机 DO/DI/AI；读不到 RS485 下挂仪表如 PH）。
- 写 DO：`http://192.168.0.x/iowrite.cgi?do01=1` —— **未确认接线前不要盲写**。
- M100 不支持 TLS，不要用 8883 MQTT。
- 有人云边缘与本地边缘计算网关互斥，不能靠 `edgeen=1` 做双路采集（已验证会关有人云）。
- 每次只让一台待配置 M100 在线，或由现场明确隔离，避免改错设备。
- ⚠️ 电脑 WLAN 2 的 `192.168.0.10` 是连有人云/M100 网段的，**不要动**。
