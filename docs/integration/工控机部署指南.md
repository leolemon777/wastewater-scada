# 工控机部署步骤（SCADA 实测环境）

把当前开发机上的整套 SCADA（前端 + ScadaHub + M100/纯水 PLC 链路）搬到另一台工控机上跑实测。目标是：**工控机成为现场数据汇聚点**（接网桥管理段 + M100 数据段 + 纯水 PLC 段），浏览器访问它即可。

## 一、工控机网络准备（管理员 PowerShell）

```powershell
# 以太网插在主网桥所在交换机（或主网桥有线侧）
# 一键配置：项目 scripts/industrial-pc-setup.ps1
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\industrial-pc-setup.ps1
```

预期结果：

- 工控机以太网拿到 `192.168.2.50`（网桥管理段）、`192.168.0.60`（M100 段）、`192.168.1.50`（纯水 PLC 段，按 SPEC 约定）
- 自动添加 `192.168.0.7/32` 主机路由（绕开工控机 WLAN 若占用默认 M100 IP）
- 自测 6 个地址（主网桥、两从站、两台 M100、混合池默认 .7）全部 OK

**若工控机不在 2.x 网段**（比如在办公室测试环境），按 `M100-IP配置-现行版本.md` 的“改 IP 标准流程”先把目标网桥/M100 的网关指到工控机所在网段，或拉一条网线到主网桥交换机。

## 二、代码同步

```powershell
# 工控机（建议与开发机同路径）
git clone https://github.com/leolemon777/wastewater-scada.git E:\Desktop\SCADA
cd E:\Desktop\SCADA
git checkout agent/pure-water-plc-scada-hub
```

## 三、依赖安装

```powershell
# 前端
npm install

# 后端（.NET 8 SDK 需先装好）
cd services\ScadaHub
dotnet restore
```

## 四、M100 本地配置（凭据不入 git）

创建 `services\ScadaHub\appsettings.local.json`：

```json
{
  "M100": {
    "Enabled": true,
    "Devices": [
      { "Enabled": true, "SourceId": "m100-daf-01", "Role": "daf", "IpAddress": "192.168.0.31", "Username": "<本地凭据文件>", "Password": "<本地凭据文件>" },
      { "Enabled": true, "SourceId": "m100-underground-01", "Role": "underground", "IpAddress": "192.168.0.8", "Username": "<本地凭据文件>", "Password": "<本地凭据文件>" }
    ]
  }
}
```

（纯水 PLC 启用时再加 `PureWaterPlc` 节，IP 用 `192.168.1.x` 段。）

## 五、启动

两个终端（或两个 PowerShell 窗口）：

```powershell
# 终端 1：Hub（后端）
cd E:\Desktop\SCADA
npm run hub:run
# 日志应出现 "M100 只读适配器启动" 与两台设备注册

# 终端 2：前端
cd E:\Desktop\SCADA
npm run dev
```

## 六、验证清单

| 检查 | 方法 | 预期 |
| --- | --- | --- |
| Hub 健康 | 浏览器 `http://192.168.2.50:18080/api/health` | `m100` 数组两台 `connected=true` |
| M100 快照 | `http://192.168.2.50:18080/api/m100/snapshots` | 气浮 `points.ph≈5.0`、地下池 `points.level≈3.x` |
| 前端 | 浏览器开 `http://192.168.2.50:5173` | 3D 气浮池气泡/刮沫动、pH 显示；中间池液位非 0 |
| 断线恢复 | 现场断一台 M100 电源 30s 再开 | 前端状态翻 offline → 恢复 live，告警出现并自动消除 |

## 七、常见问题

- **Hub 起不来报验证错误**：`appsettings.local.json` 里 IP 为空或格式错（`Enabled=true` 时每台都必须有合法 IPv4）。
- **401 认证失败**：凭据与现场不符——用本地凭据文件中的真实值修改 local 配置。
- **混合池读不到**：确认 `.7` 主机路由存在（`Get-NetRoute 192.168.0.7/32`），且工控机 WLAN 没占 `.7`。
- **前端连不上 WS**：检查防火墙放行 18080/5173 入站；或改 `VITE_SCADA_HUB_WS_URL` 指向 `ws://192.168.2.50:18080/ws/scada`。
