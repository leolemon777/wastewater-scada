# 药剂房网桥配置记录 - 2026-07-24

本文件记录药剂房新增 ST508S 无线网桥的 IP 分配与配置过程。药剂房设备是**本地上位机(非 M100)**,经无线网桥接入中控网络。配套阅读:

- [`M100网桥现场通讯调试记录-2026-06-30.md`](M100网桥现场通讯调试记录-2026-06-30.md) — 现场网桥/M100 IP 总表
- [`接入路线图.md`](接入路线图.md) — Tank Controller 上位机接入架构

## 设备性质

| 项目 | 内容 |
| --- | --- |
| 现场名称 | 药剂房 |
| 设备类型 | **本地上位机(Tank Controller / C# 罐体上位机)**,不是 M100 |
| 网桥型号 | ST508S(有人物联网,与主网桥同型号) |
| 物理链路 | 药剂房上位机 ──网线── 药剂房网桥 ─ 📶无线 ─ 主网桥 `192.168.2.66` ─ 中控网络 |
| 接入方式 | 网桥作为**站点(从站)**,无线桥接到主网桥(接入点) |

> 关键区别:药剂房是上位机,数据走 **`192.168.2.x` 管理网段**,与上位机同段;**不占用** M100 专属的 `192.168.0.x` 数据网段。中控电脑已有 `192.168.2.28`,无需改动即可互通。

| 药剂房网桥(管理) | `192.168.2.78` | `255.255.255.0` | `192.168.2.1` | 网桥管理页地址 |
| 药剂房上位机 | `192.168.2.79` | `255.255.255.0` | `192.168.2.1` | 上位机电脑静态 IP |

选址依据:`192.168.2.x` 网段已占用 `.66 .67 .68 .69 .70 .72 .74 .76 .80`,`.78` 与 `.79` 空闲且相邻,便于记忆维护。

| 项目 | 默认值 |

## 配置操作步骤

### 第 1 步:电脑临时改 IP

新网桥默认 `192.168.2.66`,电脑先临时设同网段才能进管理页。

`Win + R` → `ncpa.cpl` → 插网桥的以太网卡 → 右键属性 → 双击 IPv4 → "使用下面的 IP 地址":

```
IP 地址:      192.168.2.100
子网掩码:     255.255.255.0
默认网关:     留空
DNS:          留空
```

> 临时让位,步骤 7 会恢复成 `192.168.2.28`。

### 第 2 步:物理连接

- 网桥上电(用配套 PoE 供电模块,12-24V 被动 PoE)
- 网线一端插网桥唯一 RJ45 端口,另一端插电脑

### 第 3 步:登录网桥管理页

浏览器打开 `http://192.168.2.66`:

- 语言:简体中文
- 用户名:`admin`
- 密码:`admin01`

首次登录会要求**初始化配置**:阅读协议 → 同意 → 选择国家/地区。常规使用选"中国";若要全功率全信道,选"Compliance testing"测试模式。

### 第 4 步:配置网桥 IP(说明书 2.3.1 节)

进 配置 → 网络 / LAN / IP 设置:

```
网络模式:    网桥模式(Bridge)        ← 默认,保持不动
IP 方式:     静态 IP(Static)
IP 地址:     192.168.2.78
子网掩码:    255.255.255.0
默认网关:    192.168.2.1
```

### 第 5 步:无线配置(说明书 2.3.2 节)

药剂房网桥做**站点(从站)**,连接主网桥 `192.168.2.66`(接入点)。

**A. 工作模式:**

```
无线工作模式:  站点 (WDS / iPoll 2 / iPoll 3)
```

> 必须与主网桥对应:主网桥是"接入点 iPoll 2"就选"站点 iPoll 2";iPoll 3 同理。两边模式不一致会连不上。

**B. 发射功率:** 按实际距离调整(距离远调高,过近不要过高以免信号过强影响传输)。

**C. SSID 与无线安全:**

```
SSID:        <与主网桥 192.168.2.66 完全一致>
加密方式:     WPA2 个人
密码:        <与主网桥 192.168.2.66 完全一致>
```

> 省事做法:在 SSID 设置处点"扫描",自动发现主网桥的 SSID 直接选中,只需手填密码,模式也会自动匹配。

### 第 6 步:保存并生效

点管理界面右上角「保存更改」→ 网桥重启应用配置 → 等约 30 秒。

### 第 7 步:恢复电脑 IP 并验证

网桥已改成 `.78`,电脑改回现场网段。回到网卡 IPv4 属性:

```
IP 地址:      192.168.2.28
子网掩码:     255.255.255.0
默认网关:     192.168.2.1
```

验证:

```bash
ping 192.168.2.78
```

通了再浏览器开 `http://192.168.2.78`,能登录即成功。

## 配置主网桥前必须确认的参数

从主网桥 `192.168.2.66` 管理页记下,否则药剂房站点连不上:

| 参数 | 在哪看 | 用途 |
| --- | --- | --- |
| 接入点工作模式 | 无线设置 | iPoll 2 或 iPoll 3,药剂房站点需对应 |
| SSID 名称 | 无线设置 | 药剂房要填一致 |
| WPA2 密码 | 无线安全 | 药剂房要填一致 |

## 操作顺序速查卡

```
□ 1. 电脑改 192.168.2.100(临时)
□ 2. 网线连网桥、上电(PoE)
□ 3. 浏览器开 192.168.2.66 → admin / admin01 → 初始化(选国家)
□ 4. 配置 IP:静态 192.168.2.78 / 255.255.255.0 / 网关 192.168.2.1
□ 5. 无线:站点模式(对应主桥 iPoll) + 扫描选主桥 SSID + 填主桥 WPA2 密码
□ 6. 右上角"保存更改" → 等重启(~30s)
□ 7. 电脑改回 192.168.2.28 → ping 192.168.2.78 验证
□ 8. 登记归档:网桥 MAC、改后 IP、ping/管理页验证结果、上位机 .79 连通性
```

## 安全与边界

- 药剂房是**上位机**,不涉及 M100 的 RS485 主站冲突、`ioread.cgi`、`192.168.0.x` 数据网段等问题,不要套用 M100 配置流程。
- 上位机对外服务端口(REST / WebSocket / Modbus TCP)由上位机程序决定,不在网络层;待上位机协议明确后再对接 SCADA Hub。
- 不要把网桥管理密码写进代码或公开文档之外的文件。
- 网桥网络模式保持"网桥(Bridge)":说明书注明此模式下设备 IP 仅用于管理,不影响业务数据转发。
