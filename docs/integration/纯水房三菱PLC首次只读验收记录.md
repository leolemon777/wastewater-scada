## 1. 验收边界

本记录只用于 `FX3GA-60MR`、`FX3G-CNV-ADP`、`FX3U-ENET-ADP` 的纯水房监视接入。首次现场联调必须保持只读：

- 允许读取 `X/Y/M/D`；
- 禁止 `Write*`、Remote RUN、Remote STOP、参数写入、复位、静音和手动控制；
- 浏览器只连接本机 SCADA Hub，不直接连接 PLC；
- 未确认最终 PLC IP、CH、Open Setting 和现场授权前，`Enabled` 必须保持 `false`；
- 软件测试通过不替代设备侧和工艺侧验收。

## 4. 本地配置步骤

只有第 3 节全部确认且获得现场授权后才能执行：

1. 将 `services/ScadaHub/appsettings.local.example.json` 复制为同目录下的 `appsettings.local.json`。
2. 在本地文件中填写已查重的 PLC 数据 IP，将 `Enabled` 改为 `true`；端口保持与 GX Works2 一致，当前规格为 `5000`。
3. `appsettings.local.json` 已被 Git 忽略，不得提交现场地址或其他本地参数。
4. 重启 Hub 后查看启动日志，必须出现 `READ-ONLY`；若配置校验失败，不得绕过校验。
5. 前端继续访问本机 Hub `ws://127.0.0.1:18080/ws/scada`，不得填写 PLC 地址。

回退方法：停止 Hub，将本地文件中的 `Enabled` 改回 `false` 或移走该本地文件，再启动 Hub。此回退不修改 PLC。
