# 两份最新版管路合并说明

本次以当前主工程的 `src/components/scene` 架构为目标，吸收 `wanglizhou523/research-pipeline-paths` 版本中已验证的管路物理连接修复；没有直接覆盖两套互相冲突的旧坐标和目录。

## 已合并

- 泵端显式同心变径：泵法兰面 → 变径 → 工艺管径，避免粗管埋入泵体造成“虚碰”。
- 汇管连续壳体：汇管只保留一条结构壳体，两条支路只承载流向动画，避免三通处出现断面、重叠环和多半节管。
- 泵组统一连接：中间池、排水池、沉淀排泥、DAF 排泥、污泥外送五组路线共用精确泵端面和标准化路由表。
- 污泥外送：两台泵分别用连续的“泵端 → 立管 → 汇合点”管线，再接螺旋压滤机。
- 污泥池进管：增加法向穿墙深度，管线真正进入池体，不再停在墙面外侧。
- 进水提升泵：取消自由空气/气源式吸入口，六台提升泵全部连接到收集池实际墙面；泵位避开池角，进池管增加法向穿墙段。
- 管路端点：取消墙口、开口法兰、盲法兰上的彩色短管装饰段，端点只保留法兰/密封面，避免视觉上多出半根管。
- 主工艺廊道：继续按澄清池墙面动态计算，并避开固定 2# 控制柜。
