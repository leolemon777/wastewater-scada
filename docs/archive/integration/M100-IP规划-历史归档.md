## 附：无线网桥历史测试快照（`192.168.2.x`）

原始记录：`网桥测试/网桥配置记录.md`（项目内）。历次连通性结果摘要：

| 日期 | 结果 |
| --- | --- |
| 2026-05-25 | ✅ `.66 .67 .68 .69 .70` 全通（初装验收） |
| 2026-06-17 | ✅ `.66 .72 .74 .76` 通（延迟偏高 47-87ms）；❌ `.67 .68 .69 .70` 不通（怀疑距离/供电） |
| 2026-08-10 | ✅ `.66 .67 .74 .78` 通；❌ `.79` 药剂房上位机不通（网桥通但后接设备无响应，暂搁置）；⏳ `.68 .69 .70 .72 .76` 未测 |

2026-08-10 排障结论：`.74` 纯水房从站曾被错配成「接入点 iPoll2」，改回「站点 iPoll3」后即通；其 IP 为 DHCP，建议改静态（未确认是否已改）。

网桥配置核心参数（历次不变）：主网桥 `.66` 接入点(iPoll 3)；从站一律「站点(iPoll 3)」；新从站先单机改 IP 再上无线；WLAN 2 的 `192.168.0.10` 属有人云/M100 网段，**不要动**。无线凭据不写入 git 文档，见本地被忽略的 `docs/integration/本地凭据.local.md`。
